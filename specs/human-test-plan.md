# 真机人工测试清单 (Human device test plan)

给车主在 iPhone 17 上逐项跑完所有仍为 NOT_VERIFIED 的真机验收行。按顺序做完一遍即一次完整测试：
准备 → 权限 → 语音 → 导航 → 摄像头 → 噪声 → 生命周期 → 演示录制。每行都标了出处（spec 行号），
这里不新增任何需求。

**来源：** [STATUS.md](STATUS.md)（NOT_VERIFIED 列）、[work.json](work.json)（RUNNING / HUMAN_REQUIRED /
BLOCKED_EXTERNAL 任务）、`features/*.md` 中等级为 D 的验收行、[demo-recording.md](demo-recording.md)、
[release-plan-2026-12-04.md](release-plan-2026-12-04.md)。走查 W1–W8 的定义见 [parity-matrix.md](parity-matrix.md)。

## 手机上装的版本

- **已安装：ea7e649**。包含后视摄像头 F-20b、手机定位 F-16a、抗噪 F-04a。
- **不包含** 2026-10-27 的评审修复（b7a1714..5c3fbcd）：定位首次定位 / 权限 / 前后台恢复（b7a1714、2bbab74、
  0366f1b），抗噪门控修复、抗噪开关即时生效、中文拒绝原因（79cbfa0、751cbda、e229432），语音切换镜头的顺序、
  沿途选点和旧导航停止（0052d4c）。
- 「版本」列写 **新版本** 的行依赖这些修复：可以在 ea7e649 上先试跑并记下现象，但 **PASS 只能用 5c3fbcd
  或更新的版本记录**。写 ea7e649 的行在当前版本上就能记 PASS。

## 安全规则

- 手机固定在支架上。**开车时司机只说话，不碰屏幕。** 需要点击、看数字、切设置的步骤一律停车做，或由乘客操作。
- 「地点」列：**停车** = 车停稳（P 挡）；**行驶** = 需要真实路噪，由乘客操作和记录。
- 打电话、改系统设置这类步骤只在停车时做。

## 记录方法

- 「结果」填 PASS / FAIL / NOT_VERIFIED / BLOCKED，「备注」写看到的现象、数字、时间。没把握就写 NOT_VERIFIED。
- 需要计时的行（标 ⏱）用控制中心「屏幕录制」并打开麦克风，事后看视频计时。录屏时不要打开显示 key 的页面
  （REC-003）。
- 状态标签：聆听中 / 思考中 / 说话中 / 待命 / 出错。车辆状态看驾驶页顶部（温度、风量、座椅、车窗）。
- 测完把结果交给 agent 写进 [STATUS.md](STATUS.md)；一行一个结果，不要合并。
